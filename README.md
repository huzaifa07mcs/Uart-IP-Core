# Uart-IP-Core
A feature-complete, full-duplex UART IP core in Verilog HDL. Includes parameterized baud rate generation, 16-deep synchronous TX/RX FIFOs, hardware parity (Even/Odd/None), and comprehensive error detection (Framing, Parity, Overrun with drop-new policy). Designed for FPGA implementation and verified using SystemVerilog self-checking testbenches.
